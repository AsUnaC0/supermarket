#黑马智慧商城项目#
1.使用了vant2组件库，并按需导入
2.解决移动端vw适配，使用了postcss-px-to-viewport插件，根据屏幕进行等比例缩放
3.对requset请求方法进行封装，创建了axios实例，添加了响应拦截器和请求拦截器进行了自定义
3.进行lstorage存储模块封装，用于用户个人信息等搜索历史进行本地存储
4.对api请求进行模块封装，并将不同的api根据业务的不同进行分类，写入不同的js文件中
5.进行了路由配置，添加了路由导航守卫
6.使用了vuex仓库，并对需要存储的不同数据也进行了分模块处理
7.完善了地址管理业务，可以对地址进行增加，删除，修改和设置默认地址
